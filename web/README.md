# Браузерная версия

Та же логика, что в `tool/`, но целиком в браузере: сервера нет, хостинг
бесплатный, платить не за что. Публикуется на GitHub Pages как обычная статика.

```
файл ──▶ lib/docs.js ──▶ lib/extract.js ──▶ lib/ledger.js ──▶ lib/workbook.js
         pdf.js:          запрос к API       заказы,           ExcelJS:
         текстовый слой   прямо из           проверки,         книга той же
         или картинки     браузера           расчёты           раскладки
```

Ни один документ никуда не загружается: файл читается у вас на устройстве, в
сеть уходит только запрос к `api.anthropic.com`. Ключ хранится в `localStorage`
этого браузера — у каждого свой.

## Запустить у себя

Нужен http: модули не грузятся с `file://`.

```bash
python3 -m http.server -d web 8000   # http://127.0.0.1:8000
```

## Проверки

```bash
node --test "web/tests/*.test.js"                     # расчёты
python3 web/tests/browser_check.py <папка-с-pdf>      # сквозной прогон в Chromium
```

Первое — те же 19 проверок, что в `tool/tests/test_ledger.py`, на тех же
цифрах. Расчёты теперь живут в двух реализациях и разойтись могут молча;
пока оба набора зелёные на одних данных, порт верен.

Второе поднимает настоящий Chromium, скармливает ему настоящие PDF и
сверяет собранную книгу по ячейкам через openpyxl. Проверено на документах
заказа 666: pdf.js так же, как poppler, отличает текстовый слой от скана,
семистраничная накладная даёт 1,8 МБ картинок, книга получается с теми же
формулами и значениями.

## Чем отличается от серверной версии

| | Браузер | Сервер (`tool/`) |
|---|---|---|
| Ключ к API | у каждого свой, в браузере | один, в настройках хостинга |
| Документы | не покидают устройство | загружаются на сервер |
| Хостинг | бесплатно, Pages | нужен сервер |
| DOCX | не читается | читается |
| Общая история | нет | нет (у обоих) |

DOCX в браузере не разбирается — сводный реестр в этом формате придётся
сохранить в PDF или прогнать через `python -m tool.cli`.

## Что не проверено

Живое распознавание: в среде, где это писалось, не было ключа к API. Схема и
запрос написаны по документации, но точность на ваших сканах нужно замерить —
прогоните папку заказа 666 и сверьте с `web/tests/fixtures.js`, там тот же
разбор, переписанный с самих бумаг.
