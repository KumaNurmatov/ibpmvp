# Разбор документов по заказам

Первичные документы — договоры, спецификации, накладные, CMR, платёжки,
банковская выписка, фото — разбираются, разносятся по заказам и выгружаются
книгой Excel той же раскладки, что ведётся вручную.

Исходники и описание: `tool/README.md` в репозитории проекта.

## Переменные окружения

Задаются в Settings → Variables and secrets, вкладка **Secrets**:

| Имя | Зачем |
|---|---|
| `ANTHROPIC_API_KEY` | распознавание документов |
| `IBP_ACCESS_TOKEN` | пароль на вход; без него страницу открывает любой |

## Про диск

На бесплатном тарифе `/data` не переживает перезапуск Space. Загруженные
пакеты и кэш распознавания исчезают, когда Space засыпает, — книгу забирайте
сразу после разбора. Постоянным хранилищем Space не является.
