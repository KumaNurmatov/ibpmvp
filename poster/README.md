# LOFT — серия постеров A1 для подъездов

Три постера одной серии: логотип LOFT слева сверху, одна крупная фотография,
внизу факт про лофты. Фон — тёмная бетонная стена, под лофт-стиль.
Макет один, на каждом постере своё фото, свой факт и свой шрифт.

| Файл | Фото | Факт | Шрифт |
|---|---|---|---|
| `out/loft-a1-01-cherdak.*` | кирпичный фасад | «Loft по-английски — чердак. Первые лофты и были чердаками: художники занимали пустые фабричные этажи за копейки» | Cormorant Garamond, курсив |
| `out/loft-a1-02-svet.*` | таунхаус | «Высокие потолки и окна во всю стену придумали не дизайнеры — до электричества цеху нужен был дневной свет» | Playfair Display |
| `out/loft-a1-03-loft-law.*` | интерьер лофта | «В 1982 году Нью-Йорк разрешил жить в бывших фабриках» | Road Radio |

Под каждым фактом — строка подписи: слева контекст, справа
**© Borsan Construction**. Эта строка ставится автоматически на всех
постерах, править её в `poster.html` (класс `.copy`).

Про Loft Law: закон 1982 года (Article 7-C Multiple Dwelling Law) легализовал
жильё в бывших промзданиях Нью-Йорка — тех самых, где художники жили
самовольно. См. [1982 Loft Law](https://en.wikipedia.org/wiki/1982_Loft_Law).

## Что отдавать в печать

- `out/*.pdf` — печатный файл: **600 × 847 мм** = A1 (594 × 841) + по 3 мм вылетов
  с каждой стороны под обрез. Фотографии внутри — 4096 px по длинной стороне,
  это ~288 dpi на формате A1. Текст векторный.
- `out/*.jpg` — превью 150 dpi (3508 × 4967 px), для согласования и для соцсетей.

Макет тёмный и идёт в край, поэтому:

- заливка плотная, печать лучше ляжет на **матовую бумагу** — на глянце
  тёмный фон даёт блики и собирает отпечатки пальцев;
- попросите типографию про **композитный чёрный**, а не чистый K, иначе фон
  выйдет серым;
- цвет в макете RGB, конвертацию в CMYK делает типография под свой профиль.

## Как пересобрать

```bash
cd poster
node render.js        # нужен playwright (chromium)
```

Правки:

- фото, факты, подписи и шрифт (`font`) — массив `POSTERS` в `render.js`;
  там же `focus` — точка кадрирования фото (`object-position`);
- вёрстка, цвета и фон — `poster.html` (палитра в `:root`, бетон в `.page::before`);
- вылеты — константа `BLEED_MM` в `render.js`.

В шапке и подвале есть необязательные поля (`kicker`, `fleft`, `fright`) —
туда можно добавить адрес, сайт или QR-подпись, если нужно.

## Исходники

- `assets/photo-*.jpg` — присланные фотографии, апскейл до 4K через генератор
  (bytedance image upscale), затем JPEG q93 без цветовой субдискретизации.
  Оригиналы были 474–600 px по ширине — для A1 их не хватало.
- `assets/concrete.jpg` — фон, сгенерированная текстура бетонной стены
  (gpt_image_2_5), тоже апскейлена до 4K.
- `assets/logo.png` — логотип как прислан. `assets/logo-light.png` — он же,
  перекрашенный в светлый под тёмный фон: форма знака не менялась, поменялся
  только цвет заливки.
  Внимание: в исходном файле буквы обрезаны по краям кадра (левая стойка «L»
  и правое плечо «T» срезаны). Если есть вектор (SVG/AI/PDF) — лучше
  подложить его, печать будет чище.

## Шрифты

Все лежат в `assets/fonts`, подключены в `fonts.css`, кириллица есть у всех.

- **Cormorant Garamond**, **Playfair Display**, **Inter** — OFL, свободны
  в том числе для коммерческой печати.
- **Road Radio** (Glen Jan) — взят со шрифтового агрегатора, там он числится
  как платный: бесплатно только для личного использования. Перед тиражом
  постер №3 нужно либо закрыть лицензией у правообладателя, либо заменить
  шрифт (`font: 'roadradio'` в `render.js`). Начертания в комплекте:
  Light / Regular / Bold. Знаков нижнего регистра у шрифта нет — он
  целиком капительный, текст всегда набирается прописными.
