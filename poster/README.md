# LOFT — серия постеров A1 для подъездов

Три постера одной серии: логотип LOFT слева сверху (без изменений), одна
крупная фотография и цитата внизу. Макет один, на каждом постере своё фото
и своя цитата.

| Файл | Фото | Цитата | Шрифт цитаты |
|---|---|---|---|
| `out/loft-a1-01-sokrat.*` | кирпичный фасад с надстройкой | «Заговори, чтобы я тебя увидел» — Сократ | Cormorant Garamond, курсив |
| `out/loft-a1-02-platon.*` | таунхаус | «Хорошее начало — половина дела» — Платон | Playfair Display |
| `out/loft-a1-03-aitmatov.*` | интерьер лофта | «Человек, лишённый памяти прошлого, перестаёт быть человеком» — Чынгыз Айтматов | Road Radio |

Шрифт цитаты на каждом постере свой, логотип и подпись автора (Inter) —
общие для всей серии, они и держат её вместе.

## Что отдавать в печать

- `out/*.pdf` — печатный файл: **600 × 847 мм** = A1 (594 × 841) + по 3 мм вылетов
  с каждой стороны под обрез. Фотографии внутри — 4096 px по длинной стороне,
  это ~288 dpi на формате A1. Текст векторный.
- `out/*.jpg` — превью 150 dpi (3508 × 4967 px), для согласования и для соцсетей.

Цвет: макет в RGB. Если типография просит CMYK — конвертацию делает она же
под свой профиль (обычно Coated FOGRA39), в макете специально выбраны
несложные для печати цвета: тёплый офф-вайт `#F2EDE5` и графит `#1F1D1B`.

## Как пересобрать

```bash
cd poster
node render.js        # нужен playwright (chromium)
```

Правки:

- фото, цитаты, авторы и шрифт (`font`) — массив `POSTERS` в `render.js`;
  там же `focus` — точка кадрирования фото (`object-position`), если кадр
  нужно сдвинуть вверх или вниз;
- вёрстка (поля, размеры фото, кегли) — `poster.html`;
- вылеты — константа `BLEED_MM` в `render.js`.

В шапке и подвале есть необязательные поля (`kicker`, `fleft`, `fright`) —
туда можно добавить адрес, сайт или QR-подпись, если нужно.

## Исходники

- `assets/photo-*.jpg` — присланные фотографии, апскейл до 4K через генератор
  (bytedance image upscale), затем JPEG q93 без цветовой субдискретизации.
  Оригиналы были 474–600 px по ширине — для A1 их не хватало.
- `assets/logo.png` — логотип как прислан, без изменений.
  Внимание: в этом файле буквы обрезаны по краям кадра (левая стойка «L» и
  правое плечо «T» срезаны). Если есть исходник логотипа в векторе (SVG/AI/PDF)
  — его лучше подложить вместо PNG, печать будет чище.
## Шрифты

Все лежат в `assets/fonts`, подключены в `fonts.css`, кириллица есть у всех.

- **Cormorant Garamond**, **Playfair Display**, **Inter** — OFL, свободны
  в том числе для коммерческой печати.
- **Road Radio** (Glen Jan) — взят со шрифтового агрегатора, там он числится
  как платный: бесплатно только для личного использования. Перед тиражом
  постер №3 нужно либо закрыть лицензией у правообладателя, либо заменить
  шрифт (`font: 'roadradio'` в `render.js`). Начертания в комплекте:
  Light / Regular / Bold. Знаков нижнего регистра у шрифта нет — он
  целиком капительный, текст всегда набирается прописными.
