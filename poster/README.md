# LOFT — серия постеров A1 для подъездов

Три постера одной серии: логотип LOFT слева сверху (без изменений), фотоблок
и цитата внизу. Макет один, меняются цитата и порядок фотографий.

| Файл | Цитата |
|---|---|
| `out/loft-a1-01-sokrat.*` | «Заговори, чтобы я тебя увидел» — Сократ |
| `out/loft-a1-02-platon.*` | «Хорошее начало — половина дела» — Платон |
| `out/loft-a1-03-aitmatov.*` | «Человек, лишённый памяти прошлого, перестаёт быть человеком» — Чынгыз Айтматов |

## Что отдавать в печать

- `out/*.pdf` — печатный файл: **600 × 847 мм** = A1 (594 × 841) + по 3 мм вылетов
  с каждой стороны под обрез. Фотографии внутри — 4096 px по длинной стороне,
  это ~288 dpi на формате A1. Текст векторный.
- `out/*.jpg` — превью 150 dpi (3508 × 4967 px), для согласования и для соцсетей.

Цвет: макет в RGB. Если типография просит CMYK — конвертацию делает она же
под свой профиль (обычно Coated FOGRA39), в макете специально выбраны
несложные для печати цвета: тёплый офф-вайт `#F2EDE5` и графит `#1F1D1B`.

## Как пересобрать

```bash
cd poster
node render.js        # нужен playwright (chromium)
```

Правки:

- цитаты, авторы и раскладка фотографий — массив `POSTERS` в `render.js`;
- вёрстка (поля, размеры фото, кегли) — `poster.html`;
- вылеты — константа `BLEED_MM` в `render.js`.

В шапке и подвале есть необязательные поля (`kicker`, `fleft`, `fright`) —
туда можно добавить адрес, сайт или QR-подпись, если нужно.

## Исходники

- `assets/photo-*.jpg` — присланные фотографии, апскейл до 4K через генератор
  (bytedance image upscale), затем JPEG q93 без цветовой субдискретизации.
  Оригиналы были 474–600 px по ширине — для A1 их не хватало.
- `assets/logo.png` — логотип как прислан, без изменений.
  Внимание: в этом файле буквы обрезаны по краям кадра (левая стойка «L» и
  правое плечо «T» срезаны). Если есть исходник логотипа в векторе (SVG/AI/PDF)
  — его лучше подложить вместо PNG, печать будет чище.
- `fonts/`, `fonts.css` — Cormorant Garamond (цитата) и Inter (подписи),
  оба с кириллицей, лицензия OFL.
